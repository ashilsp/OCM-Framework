## Theoretical Overview

### The K=0 Oloid Interface ($R_d$)

* **Schwarzschild-Planck Boundary:** Reached where 3D potential necessitates a topological shift.
* **Oloid Topology ($J > 0$):** For rotating systems, the interface forms an Oloid manifold governed by two orthogonal circular arcs exhibiting **identically zero Gaussian curvature ($K = k_1 k_2 = 0$)**.
* **Laminar Flux ($\kappa$):** Converts chaotic frame-dragged turbulence into an ordered flux directed into the 4D conduit.

### Key Metrics & Mechanisms
* **Manifold Saturation ($S_M$):** Governs topological stress states and resonant nodal vibrations ($\nu_{\text{pulse}}$ with a strict 3:2 ratio for QPOs).
* **Manifold Viscosity ($\eta_M$):** Structural metric shear resistance bypassing the need for non-baryonic Dark Matter particle halos.
* **Topological Tethering ($\tau_M$):** Anisotropic drag tensor anchoring galactic warps (e.g., Radcliffe Wave, M31 satellite planes) to the primary node via angular phase-trapping.
